# Mangacorn – plan

## Teknik
- Spillet er HTML, CSS og JavaScript med `<canvas>`. Det kører i Chrome på en Chromebook uden installation.
- Al grafik tegnes med kode lige nu (enhjørning, mønter, monstre, KAPOW-effekter), så den kan byttes ud med egne tegninger senere.
- Fremskridt (mønter, købte ting, kapitel) gemmes i browseren på den enkelte computer.

## Version 1 (lavet)
- Enhjørning der går og hopper fra panel til panel. Kameraet glider til næste panel.
- Sølvmønter med en sky på.
- Monstre: Blobbo (går på jorden) og Tordenpust (flyver). Hop på dem = KAPOW.
- Power-ups: regnbuestjerne (uovervindelig i 8 sek.), sky-fjer (dobbelthop), hjerte.
- Butik: rød sløjfe, stjernebriller, heltekappe, regnbuemanke, ekstra hjerte, skyvinger.
- Kapitler bliver længere og sværere. Styring med tastatur eller touch-knapper.

## Idéer til næste skridt
- Egne tegninger af enhjørningen og monstrene.
- Flere slags paneler: panel der vender på hovedet, mørkt panel med lommelygte, boss-panel.
- Flere monstre og flere ting i butikken.
- Musik.
